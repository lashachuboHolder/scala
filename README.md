# My Manifesto

Natural Duality: Coexistance of two opposing elements.

There's a saying "Love at first sight" and I've just expereienced "Hate at first sight"

Scala is not a language. It's a labyrinth built by someone with no human empathy

The function chaining makes me want to dig in my skin. `f andThen g`. As if that wasn't bad enough, there are variants. `compose` does the same thing but backwards. `>>`, `>=>`, `pipe`, `via`, `through`, `>>>`, each library invents and new way to break your psychic

Then there are the function declarations. `x => y => x + y`. A function that takes `x` and returns a function that takes `y` and returns the sum. Such a simple addition buried in arrows. The type signature is `Int => Int => Int`. Every `=>` is another encryption you have to mentally dectrypt before you can understand what the code is doing

I have no mouth, because the moment I try to explain what is wrong with this language, someone will say it's actually very useful once you understand the theory. I must scream because there is nothing else left to do.
